# Hausser Skills

A curated collection of reusable agent skills, structured for direct use in LiteLLM and compatible skill-aware agents.

## Use in LiteLLM

In **Add New Skill**, paste the URL of the skill folder (not the raw `SKILL.md` file), for example:

`https://github.com/hausserb/open/tree/main/skills/street-beast-teemill-copy`

Then use the folder name as **Skill Name**. Each folder contains a self-contained `SKILL.md`.
